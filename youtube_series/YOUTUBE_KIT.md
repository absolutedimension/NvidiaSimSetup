## 0. Channel strategy — ONE channel or TWO? → **TWO channels.**

**Recommendation: separate English and Hindi channels.** Here's the honest reasoning.

These videos are **fully localized in the visuals**, not just the audio — the on-screen titles, diagram
labels, and captions are burned into the render (English in one, Devanagari in the other). That rules out
YouTube's "multi-language audio track" feature (the MrBeast model), which only swaps *audio* on a single
video with shared visuals. So each language is a genuinely separate video.

Given that, two channels wins:

| | Two channels (recommended) | One channel |
|---|---|---|
| **Algorithm** | Each channel builds ONE clean language/retention profile → far better recommendations | Mixed languages confuse the algorithm; it can't profile a consistent audience |
| **Subscribers** | English subs only get English; Hindi subs only get Hindi → high CTR, no "not for me" skips | Every sub gets uploads in a language half of them won't watch → low CTR drags the whole channel down |
| **Branding** | Language-native titles, thumbnails, community posts, comments | Awkward bilingual everything |
| **Upside** | Hindi tech-education is a HUGE, underserved market — it deserves its own home | Caps the Hindi growth |

**Setup:**
- **English:** `TrigunAI` (or "Universal Mind — TrigunAI")
- **Hindi:** `TrigunAI हिंदी` (or "TrigunAI Hindi")
- Same logo/banner, language-appropriate tagline. Cross-link in each description ("Watch in हिंदी → / Watch in English →").
- Both can live under one Google account (YouTube lets you run multiple channels from one login) — so it's *not* double the account overhead, just double the upload + thumbnail.

**The one caveat:** two channels = two thumbnails, two sets of comments to tend, two community tabs. At zero
audience that's modest extra effort. If you want to start lean: launch the **English channel first**, and
spin up the Hindi channel a week later once the upload rhythm feels easy. The videos are done either way.

## 2. Upload settings (every video)

- **Visibility:** Public (or Unlisted first → review → Public). Consider **Premiere** for Ep.1 to gather live viewers.
- **Category:** Education
- **Video language:** set correctly per video (English / Hindi) — helps reach + captions
- **Audience:** "No, not made for kids"
- **Made-with-AI disclosure:** the narration voice is AI (edge-TTS) + AI-generated backgrounds → tick YouTube's "altered/synthetic content" disclosure to be safe (it's about realism/deception; educational explainer is low-risk but disclose the synthetic voice).
- **Playlist:** create one per channel → "AI is the Universal Mind" → add episodes in order
- **End screen:** last 15s → "Subscribe" element + "Next episode" / "Latest upload"
- **Cards:** mid-video card linking the previous episode
- **Pinned comment** (drives engagement):
  - EN: *"Which faculty of mind should I rebuild next — Meaning, Intuition, or Will? 👇"*
  - HI: *"अगला कौन-सा एपिसोड? — Meaning, Intuition या Will? नीचे बताएं 👇"*

## 3. Thumbnails (critical — biggest CTR lever)

Each needs a bold thumbnail: a striking frame + 2–4 huge words. Concepts:
- **Ep.1 Attention** — the gold "it→animal" arc on dark; words: **"WHAT TO IGNORE"** (EN) / **"क्या अनदेखा करें"** (HI)
- **Ep.2 Learning** — the glowing loop ring; words: **"YOU CAN'T DELETE A HABIT"** / **"आदत मिटती नहीं"**
- **Ep.3 Imagination** — noise resolving into the gold form; words: **"CREATION FROM NOISE"** / **"शोर से सृजन"**
Keep the series look consistent: same font (Poppins/Mukta bold), same dark+gold palette, a small "Ep.N" tag + the Trigun logo corner. → **I can generate all 6 thumbnails next** (gpt-image-1.5 base + bold text overlay).

## 4. Publishing cadence
- Don't dump all 3 at once. **One episode/week per channel**, same day/time (builds the "appointment" habit + gives the algorithm time to learn each video).
- Order: Ep.1 → Ep.2 → Ep.3. Within a week, post EN and HI on their own channels same day.
- After Ep.3 publishes, you'll have audience signal to decide Ep.4 topic (Meaning / Intuition / Will).
