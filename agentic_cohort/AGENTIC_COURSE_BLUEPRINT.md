# Build Agentic AI Systems — Course Blueprint (upGrad-modeled)

> Step 1 of the course pipeline. Structure mirrors upGrad: Program → Module → Session →
> (video + gradable content) + BYOA capstone + completion tracking. 9 modules · 3 months · ₹35,000.
> Capstone = **BYOA — "Build Your Own Agent"** (an AI agent that does a real job of the student's).

---

## Module 1 — Welcome to the Program  *(orientation, no grade)*
- S1 · How this cohort works (live classes, GPU access, the BYOA capstone)
- S2 · Set up your environment (keys, the provided GPU, repo)
- S3 · Meet your BYOA project — pick the real job your agent will do

## Module 2 — What an Agent Actually Is  *(foundations)*
- S1 · From a chatbot to an agent: the perceive → decide → act → observe loop
- S2 · The LLM as the reasoning core (prompts, system messages, context)
- S3 · Your first tiny agent (one tool, one loop)
- 🎯 Gradable: quiz (5 Q) + "make a 1-tool agent" assignment

## Module 3 — Tool Use: Giving the Agent Hands  *(Gradable)*
- S1 · Function/tool calling — the contract between LLM and code
- S2 · Real tools: web search, code execution, APIs
- S3 · Error handling & retries (agents fail; design for it)
- S4 · Lab: wire 3 tools into your agent
- 🎯 Gradable: assignment (3-tool agent) + quiz

## Module 4 — Memory  *(Gradable)*
- S1 · Why context isn't enough — short vs long-term memory
- S2 · Vector stores & retrieval (RAG for agents)
- S3 · Conversation state & persistence
- 🎯 Gradable: add memory to your agent + quiz

## Module 5 — Planning & Multi-step Autonomy  *(Gradable)*
- S1 · Task decomposition (big goal → sub-goals)
- S2 · ReAct & plan-execute patterns
- S3 · Self-correction (the agent fixing its own mistakes)
- 🎯 Gradable: multi-step agent that plans + self-corrects

## Module 6 — BYOA Project: Part 1  *(Gradable project)*
- S1 · Scope your agent (the real job, the tools, the success metric)
- S2 · Architecture review (live, 1:1 feedback)
- 🎯 Gradable: BYOA Part 1 — scoped spec + working skeleton

## Module 7 — Orchestration & Multi-Agent Systems
- S1 · When one agent isn't enough — handoffs & roles
- S2 · Orchestrator + worker patterns
- S3 · Shared memory & coordination
- 🎯 Gradable: a 2-agent system

## Module 8 — Production: Reliability, Guardrails, Cost  *(Gradable)*
- S1 · Evaluation — how do you know it works? (the agent eval harness)
- S2 · Guardrails & safety (don't let it do the wrong thing)
- S3 · Cost & latency (token budgets, caching)
- S4 · Deploy your agent (API / schedule / UI)
- 🎯 Gradable: eval report + deployed agent

## Module 9 — BYOA Project: Part 2 — Ship It  *(Capstone)*
- S1 · Polish, eval, and harden your agent
- S2 · Demo day (present to the cohort)
- 🎯 Gradable: BYOA Final — a working agent doing a real job + a 3-min demo

---

## Totals (to plan production)
- **9 modules · ~30 sessions · ~7 gradable checkpoints · 1 two-part capstone**
- Per session = 1 short video (5–12 min) via the production pipeline + 1 gradable item
- Live cohort layer = weekly live class per module + the 1:1 BYOA reviews (Modules 6 & 9)
