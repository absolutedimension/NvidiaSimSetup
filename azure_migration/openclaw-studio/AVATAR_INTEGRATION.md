## The handshake (per video)

```
A: studio-script → reel_script.json
C: F5-TTS → full_voiceover.wav                     ← the frozen timing spine (lips will match this)
A: avatar_bridge.sh:
     pull full_voiceover.wav  (C → A)
     ensure B up (start T4, poll :8080/health)
     push VO + ensure face    (A → B)
     B: /lipsync(face + VO, still=false, preprocess=crop, enhancer=gfpgan) → make_cinematic → avatar_final.mp4
     pull avatar_final.mp4     (B → A)
     push avatar_final.mp4     (A → C)              ← printed path = handoff to the composite
C: compose reel: role=intro|corner + captions + music → final 1080×1920 (or 1920×1080)
A: studio-social (IG+FB) + studio-youtube (Short) → log → stop farms (C and B)
```

**Why feed B the reel's own F5 VO:** the avatar lips then match the exact narration the reel already
plays — one voice, perfect sync, no double audio. (SadTalker `/lipsync` accepts a supplied audio file.)

## SETUP (one-time — the cross-box credentials gap)

Box A can already reach Box C. It CANNOT yet reach Box B until these are provisioned — **do not assume
it works before this is done:**

1. **SSH key for B on A:** copy the T4 key to `~/.ssh/t4_avatar.pem` on Box A (`chmod 600`). Test:
   `ssh -i ~/.ssh/t4_avatar.pem azureuser@20.17.162.96 'curl -s 127.0.0.1:8080/health'`.
2. **Start/stop rights for B from A:** the T4 is deallocated when idle. Either (a) give Box A an `az`
   login scoped to `az vm start/deallocate -g ubuntu-new-gp_group -n ubuntu-new-gpu`, or (b) keep the
   T4 running during content hours and skip auto start/stop. Record the choice in `avatar.env`.
3. **`~/.openclaw/avatar.env` on Box A** (chmod 600) — see the template committed next to this doc.
4. **First run generates the face** on B (`~/acharya_presenter.png`); eyeball it once, then it's frozen.

## Cost / latency

- The T4 bills ~$0.5/hr while running. Default flow **starts it for the avatar step and stops it after**
  → adds ~1–2 min boot + a few minutes render per run. Acceptable for one daily reel; if we batch many,
  keep B up for the batch and stop once.
- If B is down and can't be started (creds missing), `avatar_bridge.sh` **fails soft**: the reel still
  renders WITHOUT the avatar (shader-only) and the log notes "avatar skipped (T4 unreachable)". We never
  block a daily post on the avatar.
