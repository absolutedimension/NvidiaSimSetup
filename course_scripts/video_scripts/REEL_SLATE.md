## Why these (the strategy in one line)
The funnel = **free series → email → course waitlist**. Two CTA intents only:
**Subscribe** (soft) and **Reserve your seat / Join waitlist** (hard). So we need exactly two
kinds of reel — **funnel-feeders** (drive watch+subscribe) and **launch reels** (drive the
free course waitlist, the July 10 pre-enroll signal). No third kind.

## Brand defaults applied to every reel (LOCKED after the 3 course reels, 2026-06-14)
- **Voice:** **edge-tts `en-IN-NeerjaNeural` (confident female), rate −2%** — chosen for reels
  (the series itself uses Prabhat/male). Set in `gen_reel_audio.py`.
- **Backgrounds: MOVING VIDEO, not stills.** Per scene: image-gen still (gpt-image-1.5) →
  **LTX-Video i2v** vertical clip (576×1024, 97f, via ComfyUI :8188, ~105s/clip) → boomerang-fill
  to the scene's audio duration. Driver: `render_reel3.py`.
- **Captions:** held full phrase (≤2 lines), white + heavy stroke, scale-pop entry, lower-third
  (y≈0.76) on a dark scrim. PNG-sequence overlay (qtrle/argb alpha was unreliable). NOT word-by-word.
- **Branding:** TrigunAI logo (auto-cropped) + `learn.trigunai.com` (gold) top-left on a subtle
  top gradient strip, persistent every scene. Generated by `render_reel3.py:make_branding()`.
- **Music:** ambient pad (music_service fallback — **ACE-Step not installed**, so not full cinematic;
  install ACE-Step or drop a licensed track for premium music). Ducked −13 dB under VO.
- **Hooks are curiosity hooks, not pain-agitation** (brand guardrail overrides the ad-skill default).

## Production runbook (EC2)
1. `gen_reel_audio.py <build>` → per-scene female VO + preview (human gate).
2. Ensure ComfyUI up: `curl :8188/system_stats` == 200; else `cd ~/ComfyUI && nohup setsid
   ~/comfyenv/bin/python main.py --listen 127.0.0.1 --port 8188 </dev/null >~/comfyui.log 2>&1 &`.
3. `render_reel3.py <build>` → LTX bg + captions + branding + concat + music → `<build>_FINAL.mp4`.
   Reuses cached `assets/*_ltx.mp4` + stills, so re-runs (e.g. branding tweaks) are cheap.
4. Scene/build data (image prompt + LTX motion prompt + caption) lives in `render_reel3.py:DATA`.

## Guardrails (from BRAND_HANDOFF §9 — enforced in every script)

"free for now"). Clarity, not healing. No hustle / faceless-channel energy. Only the 3 sourced
stats may appear (WEF 59%, edX +109%, NASSCOM India #1).
