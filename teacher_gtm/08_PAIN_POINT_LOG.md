# Pain-Point Log — every teacher conversation is a research touchpoint

> **Thesis being tested (user-research-education-trigunai):** most coaching-institute problems
> are WORKFLOW problems that agentic systems can solve. Acharya solves one (doubts/practice/
> retention). This log captures ALL the others, verbatim, so we build the next product from
> evidence instead of imagination.
>
> **Who writes here:** the field rep (scheduling calls, §2 answers) + Deepak (demo discovery block).
> **Feeds:** `USER_RESEARCH_EDU.md` (weekly synthesis) · `07_DEMO_CONVERSION_PLAYBOOK.md` §5
> (the solution decision tree). **Rule:** verbatim quotes, same day, or it didn't happen.

---

## 1. The pain taxonomy (tag each entry)

| Tag | Pain area | Current solution candidate |
|---|---|---|
| `DOUBT` | Doubt load / after-hours support / practice | **Acharya (core)** — sell now |
| `FEES` | Fee collection, chasing parents, dues tracking | WhatsApp fee-reminder agent (~2–3 days) |
| `PARENT` | Parent updates, complaints, PTM overhead | Auto parent progress digest (~2 days) |
| `ADMIT` | Admission inquiries not followed up, seasonal chaos | Maya-for-them white-label caller (~3–4 days) |
| `PAPER` | Test papers / DPP / notes creation time | Paper generator from concept bank (~3 days) |
| `ATTEND` | Attendance, batch scheduling, reminders | WhatsApp attendance agent (validate ≥3 asks first) |
| `RETAIN` | Students leaving to big apps / other coaching | Acharya retention story + report |
| `OTHER` | Anything else (marketing, website, staff…) | Log only — no commitments |

**Build gate:** a non-Acharya solution gets built only when (1) ≥3 institutes name the same
pain unprompted, (2) at least one will pay for it, (3) it ships in <1 week from existing
infra. Until then it stays research.

## 2. The 6 questions that harvest pains (the field rep asks 1–5, Deepak digs deeper in demo)

1. Students kitne, kaun sa exam? *(context)*
2. **"Aapke din ka sabse zyada time kis kaam mein jaata hai jo padhane se rokta hai?"** *(open — the goldmine)*
3. Raat ko doubt aaye toh kya hota hai? *(DOUBT)*
4. **"Fees, parents ko update, naye admissions — sabse bada sar-dard kaun sa?"** *(FEES/PARENT/ADMIT)*
5. Students bade apps ki taraf gaye kabhi? *(RETAIN)*
6. *(demo only)* "Agar ek assistant aapka [named pain] bina aapke time ke handle kar de, mahine ka kya value hoga aapke liye?" *(prices the next product)*
