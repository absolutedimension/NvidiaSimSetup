The assessment engine

Everything the test does — automatically.

These run on every test a student takes, so you never set, grade or diagnose by hand.

🎚️

Adaptive difficulty

Get a question wrong and Acharya drops to an easier one to find the real floor — so a weak student isn't just failed, they're located. Five question types: MCQ, true/false, match, numeric, written.

🗺️

Weak-spot diagnosis

Every answer maps to a concept and a depth — solid, shaky, or weak, and whether the basics or the application broke. A real strengths-and-gaps picture, built from actual answers.

🧠

Hesitation & confidence

It notices a right-but-slow answer (shaky, not solid) and — with confidence check on — the answers a student was sure about but got wrong: the hidden misconceptions that fail exams.

✅

Grading you can trust

Assessment is MCQ-first; code, not the AI, owns the score. No hallucinated marks — and a written answer is shown honestly beside a model answer, never faked.
